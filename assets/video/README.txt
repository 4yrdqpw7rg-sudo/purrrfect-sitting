Put the About page video in this folder, named exactly:

  behind-the-scenes.mp4

Optional: a still image named  video-poster.jpg  in  assets/photos/
will show as the thumbnail before anyone presses play. Without one the
browser shows the first frame, which is often a blur.

SIZE MATTERS. GitHub refuses any file over 100MB, and anything over about
25MB will be slow for someone watching on mobile data.

  - Keep it to 60-90 seconds. Nobody watches longer on a service page.
  - Export at 1080p, not 4K.
  - If it is still too big, run it through a free compressor such as
    HandBrake, or re-export from CapCut / iMovie at a lower bitrate.

Portrait video is fine - the player centres it with a navy surround.
Landscape fills the width and looks better.
